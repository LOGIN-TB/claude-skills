# Lead-Magneten

Plane nützliche Lead-Magneten und transparente Akquisestrecken, die Einwilligung, Datenschutz, Rechte, Barrierefreiheit und wahrheitsgemäße Aussagen berücksichtigen. Standardmäßig entsteht eine Strategie oder ein Entwurf im Chat. Erstellung bedeutet nicht automatisch Veröffentlichung, Tracking, Versand, Kontaktimport, Werbebudget oder Erfassung realer Leads.

## Grundsätze

1. **Nutzen vor Datenerfassung.** Löse ein klar begrenztes Problem und beschreibe Format, Umfang, Voraussetzungen, Lieferzeit und Grenzen korrekt.
2. **Datenminimierung.** Beginne ohne Gate oder mit dem kleinsten begründbaren Feldsatz. Name, Telefon, Unternehmen, Rolle, Größe oder Anreicherungsdaten sind keine Standardfelder.
3. **Zweckbindung.** Dokumentiere für jedes Feld Zweck, Pflichtstatus, Empfänger, Aufbewahrung und Löschung.
4. **Getrennte Einwilligungen.** Die Anforderung oder Zustellung eines Assets ist keine automatische Einwilligung in Newsletter, Nurturing, Profiling, Retargeting, Vertriebsansprache oder Partnerweitergabe. Verwende getrennte, spezifische und nicht vorangekreuzte Auswahlmöglichkeiten, soweit erforderlich.
5. **Keine Dark Patterns.** Keine fingierte Knappheit, beschämende Ablehnung, versteckte Schließen-Funktion, erzwungene Werbeeinwilligung oder erschwerte Abmeldung.
6. **Keine erfundenen Belege.** Keine erfundenen Downloads, Testimonials, Logos, Bewertungen, Ergebnisse, Benchmarks oder „kostenlos“-Aussagen mit verdeckten Pflichten.
7. **Rechte und Herkunft.** Prüfe Lizenzen und Freigaben für Texte, Daten, Vorlagen, Screenshots, Zitate, Logos, Schriften, Bilder und Gastbeiträge.
8. **Sichere Zustellung.** Keine Geheimnisse, Produktionsdaten oder dauerhaft erratbaren privaten Links; Berechtigungen, Dateiintegrität und Löschung prüfen.
9. **Entwurf vor Außenwirkung.** Versand, Upload, Publikation, Tracking, Integration und Ausgaben brauchen eine gesonderte Freigabe.

## Briefing

Ermittle nur entscheidungsrelevante Angaben:

- Geschäftsziel, Zielgruppe, Kaufphase, Problem und Belege;
- freigegebene Produktverbindung, Aussagen und nächster Schritt;
- vorhandene Inhalte, Rechte, Sprache, Barrierefreiheit und Pflegekapazität;
- Kanal und belastbare Ausgangswerte;
- Notwendigkeit des Gates und Nutzen einer unbeschränkten Alternative;
- Felder samt Zweck, Zustellung, Einwilligungsmodell, Aufbewahrung und Löschung;
- Systeme, Auftragsverarbeiter, Tracking, Budget und Verantwortliche;
- Erfolgsmaß mit Zähler, Nenner, Zeitraum, Quelle und Abbruchkriterien.

## Gate-Entscheidung und Format

- **Ohne Gate:** für Reichweite, Vertrauen, Auffindbarkeit, Bildung oder Produkthilfe.
- **Offener Kern plus optionale Fortsetzung:** versprochener Nutzen ohne Zwang, Newsletter separat.
- **Teil-Gate:** vorab klar ausweisen, was davor und danach verfügbar ist.
- **Vollständiges Gate:** nur bei verhältnismäßigem Wert und transparentem Datenzweck.
- **Konto/Testzugang:** als Onboarding mit eigenen Bedingungen, Sicherheit, Löschung und gegebenenfalls Abrechnung behandeln.

Wähle Checkliste, Entscheidungshilfe, Referenzblatt, Vorlage, Guide, Workbook, Kurs, Quiz, Webinar, Rechner, Bibliothek oder Demo nach Aufgabe, Evidenz, Produktionsfähigkeit, Barrierefreiheit, Wartung, Rechten und Produktbezug. Keine starren Seitenzahlen, Längen oder Produktionszeiten erfinden.

## Arbeitsablauf

1. Evidenzregister für Bedarf, Aussagen, Beispiele, Kennzahlen und Rechte anlegen.
2. Versprochenes Ergebnis und Ausschlüsse definieren.
3. Format wählen und gegen eine offene Alternative abwägen.
4. Gliederung mit Quellen, Verantwortlichen, Prüfung, Barrierefreiheit und Aktualisierungsdatum erstellen.
5. Asset mit dem passenden Dokument-, Tabellen-, Bild- oder Entwicklungsworkflow erzeugen.
6. Tatsachen-, Vergleichs-, Rechts-, Sicherheits-, Finanz- und Leistungsangaben prüfen.
7. Beispiele auf personenbezogene, vertrauliche oder produktive Daten kontrollieren.
8. Ergebnis erneut öffnen, Text/Links und visuelle Darstellung prüfen.
9. Vor Gate, Veröffentlichung, Verteilung oder Automatisierung Freigabe einholen.

## Erfassung, Zustellung und Messung

Erstelle vor der Umsetzung eine Datenflussübersicht:

| Schritt | Daten | Zweck | Pflicht? | Grundlage/Einwilligung | System/Empfänger | Aufbewahrung | Löschung |
|---|---|---|---|---|---|---|---|
| Formular | | | | | | | |
| Zustellung | | | | | | | |
| Newsletter | | | | | | | |
| Analyse | | | | | | | |
| Vertrieb/CRM | | | | | | | |

Formulare brauchen sichtbare Leistungsbeschreibung, eindeutige Labels, Tastaturbedienung, Fehlerhinweise, Pflichtkennzeichnung, Datenschutzhinweis und passende Einwilligungssteuerung. Die Zustellung muss wie versprochen funktionieren und darf bei getrennter Werbeeinwilligung nicht davon abhängig gemacht werden. Plane Dubletten, Bounces, Widerruf, Abmeldung, Löschung und Support.

Miss berechtigte Besuche, Formularstarts, gültige Eingaben, Zustellerfolg, separat erteilte Werbeeinwilligung, Bestätigung, Asset-Nutzung, Abmeldungen, Beschwerden, Löschungen, Zielgruppenpassung, Produktfortschritt und Vollkosten. Attribution bleibt unsicher; ein späterer Kauf beweist keine Kausalität.

Tests benötigen vorab Hypothese, Primärmetrik, Schutzmetriken, Grundgesamtheit, Zuteilung, Auswertungszeitraum, Mindestwirkung, Instrumentierungsprüfung und Datenschutzfolgen.

## Deutscher/DACH-Kontext

**Standardannahme ist Deutschland**, sofern der Auftrag kein anderes Land nennt. Für Deutschland sind insbesondere DSGVO, BDSG, TDDDG, UWG und die konkrete Kommunikationsform als Reviewpunkte zu berücksichtigen. Das ist keine Rechtsberatung und keine Rechtsgarantie; bei produktiver Erfassung, Tracking, Werbung oder sensiblen Daten ist eine qualifizierte rechtliche Prüfung erforderlich.

- **Deutschland:** Trenne Asset-Zustellung und werbliche Einwilligung. Dokumentiere Einwilligungstext, Zeitpunkt, Quelle, Version und Widerrufsmöglichkeit. Double-Opt-in (DOI) kann Nachweis- und Qualitätszwecken dienen, ist aber **keine universelle Garantie** für Rechtmäßigkeit und ersetzt weder passenden Inhalt noch Zweck-, Transparenz- und Nachweispflichten.
- **Österreich:** Prüfe DSGVO sowie österreichisches TKG und UWG separat; deutsche Bewertung nicht übertragen.
- **Schweiz:** Prüfe revDSG und UWG sowie Regeln für elektronische Werbung separat; Rollen, Auslandsbekanntgabe und Einwilligungsanforderungen können abweichen.

Tracking, Cookies, Conversion-APIs, Session-Replay und Retargeting erhalten einen eigenen Datenfluss-, Einwilligungs-, Anbieter- und Aufbewahrungsreview. Gesundheits-, Finanz-, politische, biometrische oder Minderjährigendaten standardmäßig nicht erheben.

## Ausgabeformat

1. Zielgruppenproblem und Evidenz
2. Empfohlenes Format und offene Alternative
3. Nutzenversprechen, Umfang, Gliederung und Produktbezug
4. Gate-Begründung und Feld-für-Feld-Zweck
5. Einwilligungs-, Datenschutz-, Datenfluss-, Aufbewahrungs- und Löschkonzept
6. Zustellung und optionales, separat legitimiertes Follow-up
7. Rechte, Aussagen, Barrierefreiheit und Pflege
8. Kanäle, Messung, Baseline und Testplan
9. Risiken, offene Punkte, Verantwortliche und Freigaben
10. Bei Artefakten: Pfad, Format, Quellen, Version, QA und Akzeptanztests

## Prüfliste

- [ ] Asset geöffnet und inhaltlich sowie visuell geprüft
