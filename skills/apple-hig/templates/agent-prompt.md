# Auftrag für einen Coding-Agenten

Erstelle bzw. überarbeite die Anwendung nach dem Skill `apple-hig`.
Lies zuerst `SKILL.md` und anschließend die für Zielplattform und Funktionen relevanten Referenzen.

Projekt: <Projektpfad oder Produktbeschreibung>
Hauptaufgabe: <Aufgabe der Nutzer>
Plattformen und Mindestversionen: <Ziele>
Stack: <vorhandener Stack oder begründete Auswahl>

1. Prüfe den vorhandenen Code und erstelle einen HIG-Umsetzungsplan aus der Vorlage.
2. Bewerte alle sechs Themenfamilien auf Relevanz. Leite daraus stabile Anforderungs-IDs ab und übernimm sie vollständig in das Audit.
3. Implementiere die Anwendung tatsächlich. Bevorzuge Systemkomponenten und plattformgerechte Navigation. Berücksichtige adaptive Layouts, Accessibility, Eingaben, Erscheinungsbilder sowie Fehler-/Leer-/Ladezustände von Anfang an.
4. Prüfe aktuelle Apple-Quellen bei kritischen Details und verifiziere konkrete APIs/OS-Verfügbarkeit separat.
5. Baue und starte die Anwendung. Teste Hauptabläufe, relevante assistive Bedienung und die gerenderte UI auf den verfügbaren Zielumgebungen. Behebe Fehler und teste erneut.
6. Liefere funktionierenden Code, Startanleitung, ausgefülltes Audit, Belege und offen gebliebene Blocker. Keine HIG-Konformität behaupten, wenn relevante Kriterien ungetestet sind.

Für eine Web/PWA-Anwendung gelten die HIG als Gestaltungsvorbild, nicht als Ersatz für Browserkonventionen und Web-Accessibility. Spezialfunktionen nur bei tatsächlichem Produktbedarf hinzufügen.
